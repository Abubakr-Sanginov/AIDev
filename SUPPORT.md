# Support

## Usage questions

Before asking for help:

1. Read the [README](README.md) and [runtime documentation](docs/runtimes.md).
2. Confirm that Node.js 20 or newer is installed.
3. Run `npm ci` and reproduce the problem from the latest `main` branch.
4. Confirm that the selected coding-agent CLI is installed and authenticated using its own tooling.
5. Remove credentials, private prompts, runtime state, and project data from any output you share.

Use [GitHub Discussions](https://github.com/Abubakr-Sanginov/AIDev/discussions) for usage and design questions if discussions are enabled. Maintainer availability is limited, so response times are not guaranteed.

## Bugs and feature requests

Use the repository's structured issue forms for reproducible bugs and focused feature requests. Keep one problem per issue and include the requested environment and acceptance details.

This project cannot provide support for account, authentication, model availability, billing, or service behavior controlled by third-party coding-agent providers.

## Security

Do not request security help in a public issue or discussion. Follow [SECURITY.md](SECURITY.md) for private reporting.
